G O U R M E
Premium Mushroom Marketplace & Content Platform

Technical Specification & System Manual

1. Executive Summary

GOURME is a professional-grade e-commerce and content management system developed specifically for the premium mushroom industry. The platform utilizes a Scandinavian minimalist design philosophy, combining high-end aesthetic appeal with robust technical stability. Built on the Django framework, the architecture ensures scalability, security, and exceptional performance.

2. System Architecture

The platform follows a monolithic Model-View-Template (MVT) pattern, ensuring high cohesion and simplified maintenance. The core backend is powered by Python 3.x and Django 5, providing a secure and stable environment for both transactional data and content delivery.

2.1 Database Specification

The system utilizes a relational SQLite database for the current development and initial production phase, optimized for high read speeds. The schema is fully compliant with PostgreSQL for future enterprise scaling.

3. Core Functional Modules

3.1 Dynamic Content Management (CMS)

The "Page-as-a-Service" logic allows administrators to create and manage an unlimited number of pages without developer intervention. Every page supports custom Hero banners, sub-headlines, and rich body text. Furthermore, the "Featured Association" system allows pages to dynamically display specific product collections or blog articles based on the page's unique slug.

3.2 Advanced Storytelling Engine

The platform integrates a sophisticated storytelling module. Articles support "Content Blocks," allowing for a modular layout of headings, paragraphs, high-resolution images with captions, and responsive 16:9 video embeds. This enables a rich, editorial-style experience for recipes and educational content.

3.3 Lead Acquisition & Communication

A mission-critical contact system captures 100% of visitor inquiries. This data is synchronized with a real-time notification engine and a custom WhatsApp integration, allowing for immediate lead conversion through direct messaging directly from the administration dashboard.

4. Administrative Organization

The backend administration is segmented into four strategic pillars to streamline operations:

Group Responsibility Key Assets
SHOP Commercial Operations Products, Categories, Sales Pages
DISCOVER Content Marketing Articles, Recipes, Story Pages
VALUE Promotional Strategy Offers, Combos, Subscriptions
UTILITY Backend Support Contact Leads, Utility Pages

5. Deployment & Security

The system implements industry-standard security protocols, including Cross-Site Request Forgery (CSRF) protection, XSS filtering, and secure password hashing. Regular snapshots are automated and stored in the localized /backups/ directory for disaster recovery.
